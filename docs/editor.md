# 편집 화면 (작업 중)

[← README](../README.md)

> **이 문서는**
> - 자동으로 만든 결과를 직접 고치고 싶은 사람을 위한 문서예요
> - 아직 다듬는 중인 기능이라 화면 구성이 바뀔 수 있어요. 쓰지 않아도 결과는 완성돼요
> - `npx ai-url-to-feed <주소> --edit`로 실행하면 다 만든 뒤 브라우저에 열려요
> - 고칠 수 있는 것은 구간·재생 속도·배경색(테두리·모서리)·순서·삭제예요
> - 고친 내용은 오른쪽 위 **내보내기**를 눌러야 파일에 반영돼요

![편집 화면: 재생 속도 1.5x → 구간 자르기 → 배경색 변경 → 내보내기](assets/editor.gif)

## 고칠 수 있는 것

| 고칠 것 | 방법 |
|---|---|
| 영상 구간 | 오른쪽 **구간** 도구를 고르고, 아래 타임라인의 초록 구간 양끝을 끌어요 |
| 재생 속도 | **속도** 도구에서 0.8x~2.0x |
| 배경색·테두리·모서리 | **배경** 도구. 모든 게시물에 한 번에 적용돼요 |
| 순서·삭제 | 왼쪽 목록에서 번호 아래 위·아래 버튼, 휴지통 |

편집 내용은 바로 저장되지만 파일은 그대로예요. 오른쪽 위 **내보내기**를 누르면 파일을 다시 만들고 자동 검사를 해요. 다 됐으면 **다 됐어요 — 완성본 확인**에서 승인해요.

화면을 닫으려면 편집 화면을 띄운 터미널에서 Ctrl+C를 눌러요.
