# 동작 방식

[← README](../README.md)

> **이 문서는**
> - 결과가 어떻게 만들어지고 무엇을 검사하는지 알고 싶은 사람을 위한 문서예요
> - AI(planner·editor)는 계획과 편집값만 쓰고, 녹화·합성·검사는 스크립트가 해요
> - 자동 검사 7가지를 통과해야 완성이에요. 통과 여부는 AI가 아니라 검사 스크립트가 정해요
> - 명령줄은 Claude Code를 허용된 명령만 쓰게 띄우고, 멈추면 그 아래 프로세스까지 묶음째 꺼요
> - 만든 파일과 기록은 `runs/<프로젝트>/`에 남아요

## 다섯 단계

| 단계 | 하는 쪽 | 하는 일 | 결과 (`runs/<프로젝트>/`) |
|---|---|---|---|
| 장면 계획 | AI planner | 사이트를 둘러보고 찍을 흐름과 녹화 시나리오를 써요. 미리 돌려 보며 고쳐요 | `plan/` |
| 녹화 | 스크립트 | 시나리오대로 1080×1920으로 녹화해요. 저장 요청은 막아요 | `raw/` |
| 구간·속도 정하기 | AI editor | 녹화본에서 쓸 구간·재생 속도·이미지 장면을 정해요 | `edit/edits.json` |
| 파일 만들기 | 스크립트 | 1080×1440 배치·배경색·테두리로 합성해요 | `export/` |
| 자동 검사 | 스크립트 | 아래 7가지를 검사해서, 걸리면 editor에게 돌려보내요 | `gate/` |

다음에 할 일은 항상 상태(`npx ai-url-to-feed status <프로젝트>`)로 정해요. 그래서 중간에 멈춰도 그 단계부터 이어서 할 수 있어요.

## 자동 검사

| 검사 | 확인하는 것 |
|---|---|
| 파일 규격 | 1080×1440, H.264·30fps 영상과 PNG 이미지 |
| 영상 길이 | 최대 길이(기본 20초) 이하 |
| 빈 화면 | 영상의 첫·마지막 장면과 이미지가 화면 전환 중의 빈 화면이 아닌지 |
| 배경색 | 모든 게시물의 배경이 같은 색인지, `--bg`로 정한 색인지 |
| 같은 화면 반복 | 서로 다른 게시물에 같은 화면이 들어가지 않았는지 (PSNR 35dB 이상이면 같은 화면) |
| 멈춘 영상 | 영상 구간 안에서 화면이 실제로 움직이는지 (거의 멈췄으면 이미지로 쓰게 해요) |
| 반복 이음새 | 반복 재생 영상의 끝과 처음이 자연스럽게 이어지는지 |

같은 화면·멈춘 영상의 기준값은 실제로 만든 결과 네 벌에서 쟀어요. 화면 내용이 의도한 장면인지는 검사하지 않고 AI 판단에 맡겨요.

## 명령줄과 Claude Code

- `npx ai-url-to-feed <주소>`는 주소와 옵션을 `projects.yaml`에 적고, 이 폴더에서 `claude -p "<프로젝트> 하네스 시작해줘"`를 띄워요. Claude Code는 [CLAUDE.md](../CLAUDE.md)의 순서대로 에이전트와 스크립트를 돌려요.
- Claude Code는 `.claude/settings.json`의 허용 목록(하네스 스크립트)만 실행할 수 있어요. 승인·거절·삭제는 사람이 친 명령일 때만 기록해요.
- Claude Code를 자기 프로세스 묶음으로 띄워서, Ctrl+C·삭제로 멈추면 에이전트가 돌리던 도구·브라우저까지 함께 꺼요.

## 파일 위치

```text
runs/<프로젝트>/
├── plan/              촬영 계획, 녹화 시나리오
├── raw/               녹화본 (1080×1920)
├── edit/edits.json    구간·속도·배경색
├── export/            게시물 파일 01.mp4, 02.png …
└── gate/              검사 결과
runs/.harness/log/     진행 기록, Claude Code 기록 (<프로젝트>-claude.log)
```
