# 자주 묻는 질문

[← README](../README.md)

> **이 문서는**
> - 쓰기 전에 시간·비용·쓸 수 있는 사이트가 궁금한 사람을 위한 문서예요
> - 한 사이트에 약 12분, Claude Code 사용량 $2.4~2.6 (API 요금 기준, stuckyi.studio 실측)
> - 로그인이 필요한 사이트는 아직 찍을 수 없어요
> - 녹화할 때 사이트에 데이터를 남기지 않아요

## 시간과 비용은 얼마나 드나요?

stuckyi.studio를 빈 폴더에서 처음부터 만든 실측값이에요 (2026-10-04, 두 번).

| 걸린 시간 | 게시물 | Claude Code 사용량 |
|---|---|---|
| 12분 7초 · 12분 51초 | 6개 · 7개 | $2.63 · $2.43 (API 요금 기준) |

시간 대부분은 AI가 사이트를 둘러보고 장면을 정하는 데(6~9분) 들어요. 실행이 끝나면 그 실행의 사용량이 터미널에 나와요. 사이트가 복잡할수록 길어져요.

## 어떤 사이트에 쓸 수 있나요?

주소로 열리는 공개 웹사이트요. 모바일 화면(360×640)으로 녹화하니 모바일에서 잘 보이는 사이트가 좋아요. 직접 만들었거나 공개해도 되는 사이트에 써 주세요.

## 녹화하면 사이트에 기록이 남지 않나요?

저장 요청(글 등록·업로드 등)과 방문 통계 요청을 막고 녹화해요. 데이터를 읽는 요청은 통과시켜 화면은 그대로 나와요.

## 결과물은 어떻게 쓰나요?

`runs/<프로젝트>/export/`의 mp4·png를 번호 순서대로 인스타그램에 올리면 돼요. 일반 파일이라 다른 편집 툴에서 더 고쳐도 돼요. 게시 문구와 업로드는 직접 해요.

## Windows·Linux에서도 되나요?

실제 사이트로 끝까지 확인한 건 macOS예요. Linux(Ubuntu)와 Windows는 푸시마다 자동 테스트만 통과하고, 실제 녹화는 아직 확인하지 않았어요.
