# 자주 묻는 질문

[← README](../README.md)

## 코딩을 몰라도 쓸 수 있나요?

터미널에 명령 몇 줄을 붙여 넣는 것만 필요해요. 설치 세 줄과 `npx ai-url-to-feed 내사이트.com` 한 줄이면 AI가 끝까지 만들고, 녹화 시나리오 코드도 AI가 써요. 터미널이 낯설면 `npx ai-url-to-feed ui`로 브라우저의 시작 화면을 열어 단계마다 할 일을 보며 진행해도 돼요.

## 중간에 확인하거나 승인해야 하나요?

아니요. 기본(자동 생성)은 주소만 넣으면 끝까지 자동으로 만들고, 크기·길이·빈 화면·배경색은 자동 검사가 봐요. 결과를 내 취향대로 다듬고 싶을 때만 **편집 모드**(`--edit`)로 한 번 승인해요.

## Claude Code 창을 따로 열어야 하나요?

명령줄로 쓰면 아니요. `npx ai-url-to-feed`가 Claude Code를 화면 없이 띄워 대신 진행해요. 로그인만 한 번 해 두면 돼요. 화면(`ui`)으로 진행하거나 `--no-ai`를 쓸 때만 Claude Code를 직접 열어 문장을 붙여 넣어요.

## 시간과 비용은 얼마나 드나요?

Claude Code 사용량이 들어요. 실제로 돌려 확인한 값이에요 (사용량은 planner·editor 에이전트 기준).

| 경우 | 걸린 시간 | 사용량 |
|---|---|---|
| 단순한 사이트, 대화로 진행, 게시물 5개 | 약 5분 | 약 8만 토큰 |
| stuckyi.studio, 명령줄 한 줄, 게시물 7개 (검사에 한 번 걸려 다시 고침) | 약 17분 | 약 21만 토큰 |
| 복잡한 사이트, 촬영 계획을 세 번 고침 | 약 23분 | 약 33만 토큰 |

녹화와 내보내기는 각각 1~2분이에요. 시간 대부분은 AI가 사이트를 둘러보고 장면을 정하는 데 들어요. 편집 모드면 여기에 내가 다듬는 시간이 더해져요.

## 어떤 사이트에 쓸 수 있나요?

주소로 열리는 웹사이트와 내 컴퓨터에서 띄운 개발 서버요. 모바일 화면으로 녹화하니 모바일에서 잘 보이는 사이트가 좋아요. 로그인이 필요한 화면은 아직 못 찍어요. 직접 만들었거나 공개해도 되는 사이트에 써 주세요.

## 녹화하면 사이트에 기록이 남지 않나요?

기본으로 저장 요청(글 등록·업로드 등)과 방문 통계 요청을 막고 녹화해요. 데이터를 읽는 요청(Firestore 읽기 등)은 통과시켜 화면은 그대로 나와요. 저장 장면까지 찍어야 할 때만 `projects.yaml`에서 `allow_writes: true`로 직접 허용해요 ([설정](configuration.md)).

## 결과물은 어떻게 쓰나요?

`runs/<프로젝트>/export/`의 mp4·png를 인스타그램에 순서대로 올리면 돼요. 일반 파일이라 다른 편집 툴에서 더 고쳐도 돼요. 게시 문구 작성과 업로드는 직접 해요.

## Windows에서도 되나요?

아직 확인하지 않았어요. macOS에서만 확인했어요. Linux는 `npx playwright install --with-deps chromium`과 한글 폰트가 필요할 수 있어요.
