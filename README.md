# ai-url-to-feed

**URL만 넣으면, 인스타그램에 바로 올릴 수 있는 3:4 영상·이미지가 나와요.**

![시작 화면에 URL 입력 → AI가 녹화하는 중 → AI가 파일을 만드는 중 → 자동으로 완성 → 결과를 게시물처럼 넘겨 보기](docs/assets/hero.gif)

- **페이지마다 동작 흐름을 직접 캡처하지 않아도 돼요.** AI가 사이트를 둘러보고 주요 흐름을 녹화해요.
- **캡처한 뒤 배경색·배치를 다시 작업하지 않아도 돼요.** 1080×1440 게시물 규격으로 맞춰 나와요.

<sub>이 저장소의 시작 화면에 [stuckyi.studio](https://stuckyi.studio) 주소를 넣고 기본 진행 방식(자동 생성)으로 진행한 실제 화면이에요. 아래 자막만 덧붙였고, AI가 녹화하고 파일을 만드는 시간(실제 5~25분)은 몇 초로 줄였어요 · 선명한 버전 [hero.mp4](docs/assets/hero.mp4)</sub>

## 한눈에

| 필요한 것 | 입력 | 결과 |
|---|---|---|
| macOS · Node.js 22.2+ · ffmpeg · [Claude Code](https://claude.com/claude-code) | 웹사이트 주소 | `runs/<프로젝트>/export/`의 `01.mp4`, `02.png` … (5~10개) |

기본은 주소를 넣으면 끝까지 자동으로 만들어요. 확인하거나 승인할 필요가 없어요. AI 작업은 한 프로젝트에 5~25분이에요.

## 빠른 시작

```bash
git clone https://github.com/tadkim/ai-url-to-feed.git && cd ai-url-to-feed
npm install && npx playwright install chromium
npm start        # 브라우저에 시작 화면이 열려요
```

1. 시작 화면에 사이트 주소를 넣고 진행 방식을 골라요 (`stuckyi.studio`처럼 `https://` 없이도 돼요).
2. 화면에 나온 문장 `stuckyi 하네스 시작해줘`를 복사해 Claude Code에 붙여 넣어요.
3. 기다리면 `runs/stuckyi/export/`에 파일이 생겨요. 진행 상황은 시작 화면에 보여요.

| 진행 방식 | 이렇게 돼요 | 내가 할 일 |
|---|---|---|
| **자동 생성** (기본) | 녹화 → 게시물 파일 → 자동 검사까지 멈추지 않고 진행해요 | 없어요. 끝나면 결과 폴더를 열어요 |
| **편집 모드** | 똑같이 자동으로 만든 뒤 멈춰요 | 편집 화면에서 구간·속도·배경색을 내 취향대로 바꾸고, 한 번 승인해요 |

![시작 화면: 진행 방식, 단계별 진행 표시와 체크 항목, 지금 할 일](docs/assets/start.png)

Claude Code는 **새 터미널 창에서 이 폴더로 이동해** `claude`로 열어요 (처음 한 번 폴더 신뢰는 Yes).
`stuckyi`는 주소로 정해지는 프로젝트 이름이에요. 진행 방식은 시작 화면에서 언제든 바꿀 수 있어요. 단계별 설명은 [시작하기](docs/getting-started.md)에 있어요.

## 세부 수정 도구

자동으로 만든 결과를 그대로 써도 되고, **편집 모드**에서 구간·재생 속도·배경색을 내 취향대로 다듬은 뒤 승인할 수도 있어요.
자동 생성으로 끝낸 뒤에도 시작 화면에서 **편집 모드로 바꿔 다듬기**를 누르면 돼요.

![편집 화면: 재생 속도 1.5x → 구간 자르기 → 배경색 변경 → 내보내기](docs/assets/editor.gif)

사용법은 [편집 화면](docs/editor.md)에 있어요.

## 할 수 있는 것 · 할 수 없는 것

| 할 수 있어요 | 할 수 없어요 |
|---|---|
| 배포된 사이트, 내 컴퓨터의 개발 서버 녹화 | 로그인이 필요한 사이트 |
| 모바일 화면(360×640)을 3배 화질로 녹화 | 데스크톱 화면 크기 녹화 |
| 인스타그램 3:4(1080×1440) 게시물 | 4:5, 9:16 등 다른 규격 |
| 영상(화면 1개)·이미지(화면 1~3개) 섞어 5~10개 | 영상 한 장에 화면 2개 이상 |
| 구간·재생 속도·배경색·테두리·모서리 편집 | 소리, 글자·자막 넣기 |
| URL만 넣고 승인 없이 끝까지 자동 생성 | 게시 문구 작성, 인스타그램 업로드 |
| 크기·길이·빈 화면·배경색 자동 검사 | |
| 편집 모드: 내 취향대로 다듬고 승인, 다시 찍기 요청 | |
| 사이트에 데이터를 남기지 않고 녹화 | |

macOS에서 확인했어요. Windows·Linux는 아직 돌려 보지 않았어요.
