# ai-url-to-feed

**URL만 넣으면, 인스타그램에 바로 올릴 수 있는 3:4 영상·이미지가 나와요.**

![시작 화면에 URL 입력 → AI가 녹화하는 중 → 녹화 확인·승인 → AI가 파일을 만드는 중 → 완성본을 게시물처럼 넘겨 보고 승인](docs/assets/hero.gif)

- **페이지마다 동작 흐름을 직접 캡처하지 않아도 돼요.** AI가 사이트를 둘러보고 주요 흐름을 녹화해요.
- **캡처한 뒤 배경색·배치를 다시 작업하지 않아도 돼요.** 1080×1440 게시물 규격으로 맞춰 나와요.

<sub>이 저장소의 시작 화면에 [stuckyi.studio](https://stuckyi.studio) 주소를 넣고 진행한 실제 화면이에요. 아래 자막만 덧붙였고, AI가 녹화하고 파일을 만드는 시간(실제 5~25분)은 몇 초로 줄였어요 · 선명한 버전 [hero.mp4](docs/assets/hero.mp4)</sub>

## 한눈에

| 필요한 것 | 입력 | 결과 |
|---|---|---|
| macOS · Node.js 22.2+ · ffmpeg · [Claude Code](https://claude.com/claude-code) | 웹사이트 주소 | `runs/<프로젝트>/export/`의 `01.mp4`, `02.png` … (5~10개) |

AI가 녹화하고 만들고, 사람은 화면에서 두 번 확인해 승인해요. AI 작업은 한 프로젝트에 5~25분이에요.

## 빠른 시작

```bash
git clone https://github.com/tadkim/ai-url-to-feed.git && cd ai-url-to-feed
npm install && npx playwright install chromium
npm start        # 브라우저에 시작 화면이 열려요
```

시작 화면에 사이트 주소를 넣으면, 7단계 중 지금 어디이고 무엇을 할 차례인지 알려 줘요.

![시작 화면: 7단계 진행 표시, 단계별 체크 항목, 지금 할 일](docs/assets/start.png)

| 단계 | 누가 | 하는 일 |
|---|---|---|
| 1. 준비 | 컴퓨터 | 설치 상태를 자동으로 확인해요 |
| 2. 사이트 등록 | 나 | 시작 화면에 주소를 넣어요 |
| 3. 녹화 | AI | Claude Code에 `stuckyi 하네스 시작해줘` (화면에서 복사). 녹화하는 동안 화면에 **AI가 만드는 중**이 보여요 |
| 4. 녹화 확인 | 나 | **녹화 확인** 화면에서 녹화본을 보고 승인하거나 고칠 점을 적어요 |
| 5. 게시물 만들기 | AI | Claude Code에 `stuckyi 이어서 해줘`. 파일을 만드는 동안 화면에 **AI가 만드는 중**이 보여요 |
| 6. 다듬기 (선택) | 나 | 편집 화면에서 구간·속도·배경색을 고쳐요 |
| 7. 완성 | 나 | **완성본 확인** 화면에서 게시물처럼 넘겨 보고 승인해요 |

Claude Code는 **새 터미널 창에서 이 폴더로 이동해** `claude`로 열어요 (처음 한 번 폴더 신뢰는 Yes).
`stuckyi`는 주소로 정해지는 프로젝트 이름이에요. 단계별 설명은 [시작하기](docs/getting-started.md)에 있어요.

## 세부 수정 도구

AI가 만든 결과를 그대로 써도 되고, 편집 화면에서 구간·재생 속도·배경색을 직접 다듬을 수도 있어요.
완성본 확인 단계에서 **편집 화면에서 다듬기**를 눌러 열어요.

![편집 화면: 재생 속도 1.5x → 구간 자르기 → 배경색 변경 → 내보내기](docs/assets/editor.gif)

사용법은 [편집 화면](docs/editor.md)에 있어요.

## 할 수 있는 것 · 할 수 없는 것

| 할 수 있어요 | 할 수 없어요 |
|---|---|
| 배포된 사이트, 내 컴퓨터의 개발 서버 녹화 | 로그인이 필요한 사이트 |
| 모바일 화면(360×640)을 3배 화질로 녹화 | 데스크톱 화면 크기 녹화 |
| 인스타그램 3:4(1080×1440) 게시물 | 4:5, 9:16 등 다른 규격 |
| 영상(화면 1개)·이미지(화면 1~3개) 섞어 5~10개 | 영상 한 장에 화면 2개 이상 |
| 구간·재생 속도·배경색·테두리·모서리 편집 | 소리, 글자·자막 넣기 |
| 거절 전후 결과를 나란히 비교해 승인 | 게시 문구 작성, 인스타그램 업로드 |
| 크기·길이·빈 화면·배경색 자동 검사 | |
| 사이트에 데이터를 남기지 않고 녹화 | |

macOS에서 확인했어요. Windows·Linux는 아직 돌려 보지 않았어요.
